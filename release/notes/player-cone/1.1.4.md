光锥音乐 Provider 1.1.4

- 支持光锥的 TTML 歌词：此前只有 TTML 歌词的歌曲不会显示歌词，现在会转换为逐字歌词发布。
- 同时附带 TTML 原文：Bridge 5.1.0 据此把对唱歌词按演唱者分到左右两侧、识别和声行，并读取其中的翻译。旧版 Bridge 会忽略这部分，只显示逐字歌词。
- 带全局偏移、无法可靠解析或过大的 TTML 不随附原文，只发布歌词本身；元数据过大时自动去掉 TTML 原文再发布。
- 新增支持光锥 GO（ink.trantor.coneplayer.go，已核对 v1.3.0）：取词方式与正式版相同。使用 GO 版需要在 LSPosed 中为本插件勾选“光锥 GO”。

Cone Player Provider 1.1.4

- Supports Cone's TTML lyrics: songs that only had TTML lyrics showed none before; they are now converted to a word-timed lyric and published.
- The TTML document is attached as well, so Bridge 5.1.0 can place duet lines on the side of their singer, recognise background vocals and read the translation it contains. Older Bridge versions ignore it and show the word-timed lyric only.
- A TTML document with a global offset, one that cannot be parsed reliably, or one that is too large is not attached; the lyric itself is still published. If the metadata would be too large, it is published again without the TTML.
- Adds 光锥 GO (LightCone GO, ink.trantor.coneplayer.go, checked against v1.3.0): lyrics are read the same way as in the formal build. Tick "光锥 GO" in this module's LSPosed scope to use it.
