光锥音乐 Provider 1.1.4

- 支持光锥的 TTML 歌词：此前只有 TTML 歌词的歌曲不会显示歌词，现在会转换为逐字歌词发布。
- 同时附带 TTML 原文：Bridge 5.1.0 据此把对唱歌词按演唱者分到左右两侧、识别和声行，并读取其中的翻译。旧版 Bridge 会忽略这部分，只显示逐字歌词。
- 含全局偏移或过大的 TTML 不随附原文；若能解析出歌词，则仍发布转换后的歌词。TTML 无法解析时不能生成对应歌词。元数据过大时会尝试去掉 TTML 原文再发布。
- 新增光锥 GO（ink.trantor.coneplayer.go，v1.3.0）适配：已静态核对取词入口和正式版一致，设备上确认了翻译按钮；GO 版完整歌词链路仍需设备验收。使用 GO 版需要在 LSPosed 中为本插件勾选“光锥 GO”。

Cone Player Provider 1.1.4

- Supports Cone's TTML lyrics: songs that only had TTML lyrics showed none before; they are now converted to a word-timed lyric and published.
- The TTML document is attached as well, so Bridge 5.1.0 can place duet lines on the side of their singer, recognise background vocals and read the translation it contains. Older Bridge versions ignore it and show the word-timed lyric only.
- TTML with a global offset or over the size limit is not attached, but converted lyrics are still published if parsing succeeds. Unparseable TTML cannot produce lyrics. If the metadata is too large, the Provider attempts publication again without TTML.
- Adds a 光锥 GO (LightCone GO, ink.trantor.coneplayer.go, v1.3.0) profile. The lyric hook targets were checked statically against the formal build and its translation button was confirmed on a device; the complete GO lyric path still needs device acceptance. Tick "光锥 GO" in this module's LSPosed scope to use it.
