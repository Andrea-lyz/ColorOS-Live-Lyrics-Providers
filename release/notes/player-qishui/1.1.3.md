汽水音乐 Provider 1.1.3

- 首个通过 ColorOS Live Lyrics Bridge 商店分发的版本，可在 Bridge 商店中安装和更新。
- 新增状态接口：Bridge 在没有 Root 时可显示本插件是否已在 LSPosed 中启用。
- 新增“申请作用域”入口：在 Bridge 商店卡片或本插件设置页一键向 LSPosed 申请播放器作用域，由 LSPosed 弹窗确认。
- 新增插件自检诊断（默认关闭），用于排查问题；不改变取词与发布行为。
- 歌词获取、解析与发布代码与 1.1.2 相同；共用的启动流程改为诊断出错时不影响歌词 Hook。

QiShui Music Provider 1.1.3

- First release distributed through the ColorOS Live Lyrics Bridge store.
- Adds a status endpoint so the Bridge can show whether this module is enabled in LSPosed without root.
- Adds a "request scope" entry: ask LSPosed for the player scope from the Bridge store card or this module's settings; LSPosed shows the confirmation.
- Adds a self-check diagnostics page (off by default).
- Lyric fetching, parsing and publishing are the same as 1.1.2; the shared startup now keeps lyric hooks running if diagnostics fail.
