Salt Player Provider 1.1.4

- 适配椒盐音乐 12.7.0-beta01：该版本改变了媒体会话中的歌曲 ID 格式，导致 1.1.3 取到的歌词始终被判为“不是当前歌曲”而不发布，锁屏和流体云不显示歌词。现在会识别新格式并正常发布。
- 新格式中按播放队列位置生成的 ID 会随队列调整而变化，不作为歌曲身份使用，改用曲名、歌手和时长判断是否为同一首歌。
- 旧版椒盐音乐使用的 ID 格式保持原有处理方式。歌词获取、解析与发布逻辑与 1.1.3 相同。
- 已在 12.7.0-beta01 真机上确认锁屏歌词显示和切歌更新。

Salt Player Provider 1.1.4

- Supports Salt Player 12.7.0-beta01. That version changed the song ID format in its media session, so 1.1.3 treated every lyric as belonging to another song and never published it; lyrics did not appear on the lock screen or Fluid Cloud. The new format is now recognised and lyrics are published again.
- In the new format, IDs derived from the queue position change when the queue is edited, so they are not used as song identity; title, artist and duration decide whether it is the same song.
- The ID format used by earlier Salt versions is handled as before. Lyric fetching, parsing and publishing are the same as 1.1.3.
- Lock-screen lyrics and updates on song change were confirmed on a 12.7.0-beta01 device.
