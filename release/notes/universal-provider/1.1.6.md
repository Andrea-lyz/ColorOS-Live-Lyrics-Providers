通用播放器 Provider 1.1.6

- 修复首页不更新：播放器更新歌曲信息时，系统进程向本 App 发送首页数据会被系统拒绝，首页可能长时间停在“等待播放”或旧歌曲。现在改为以系统进程身份发送。歌词获取与发布不受此问题影响。
- 修复歌名缺失：部分播放器开启状态栏/蓝牙歌词时（例如 Sonify），歌曲开头标题位置是一句无法还原的歌词，此前整首歌都没有歌名。现在只要之后能从显示字段或“歌手 - 歌名”中还原出真实歌名，就会补上；无法还原的歌词行仍不会被当作歌名。
- 首页在识别结果没有歌名时，显示查找歌词实际使用的歌名和歌手，与取到的歌词保持一致。
- 新增首页快照的诊断日志（在设置中打开“Logcat”后输出，切换后无需重启 App）：记录快照的发送、接收和请求，便于排查首页一直显示“等待播放”。日志不含歌名、歌手或包名。
- 已知问题：Sonify 开启状态栏歌词时，锁屏歌词正常，但动态封面不加载；关闭状态栏歌词即可恢复。原因在 Bridge 的封面匹配，尚未修复。

Universal Player Provider 1.1.6

- Fixes Home not updating: when a player updated its track, the system process's delivery of Home data to this app was rejected by the system, so Home could stay on "Waiting for playback" or an old song for a long time. It is now sent as the system process. Lyric fetching and publishing were not affected.
- Fixes missing titles: with status-bar or Bluetooth lyrics on (for example Sonify), some players start a song with an unrecoverable lyric line in the title, which left the whole song without a title. The title is now filled in as soon as the real one can be recovered from the display fields or an "Artist - Title" value; an unrecoverable lyric line is still never used as the title.
- When the recognised track has no title, Home shows the title and artist the lyric lookup actually used, so it matches the lyrics found.
- Adds diagnostic logs for the Home snapshot (written when "Logcat" is on in Settings, no app restart needed): sending, receiving and requesting snapshots, to help find out why Home stays on "Waiting for playback". The logs contain no titles, artists or package names.
- Known issue: with Sonify's status-bar lyrics on, lock-screen lyrics work but animated artwork does not load; turning status-bar lyrics off restores it. The cause is in Bridge artwork matching and is not fixed yet.
