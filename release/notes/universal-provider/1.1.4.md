通用播放器 Provider 1.1.4

- 首个通过 ColorOS Live Lyrics Bridge 商店分发的版本，可在 Bridge 商店中安装和更新。
- 新增状态接口：Bridge 在没有 Root 时可显示本插件是否已在 LSPosed 中启用。
- 歌词来源严格按设置的优先级取用：不再因为低优先级来源带逐字或翻译就抢在前面；只有制作人员信息的结果不会提前结束查找。
- 提升匹配准确性：比较去掉版本后缀的核心标题与全部艺人，不再把纯音乐上传当作演唱版本，兼容带空格的 QRC 时间戳，识别“词/曲”署名行，并在分数下限内比较前几个候选。
- 自动未命中不再永久缓存为“无歌词”：播放器补齐艺人或时长后会重试，调整来源顺序后也会重新查找。
- QQ 音乐的几个搜索接口互不影响，其中一个失败不再让整个来源消失；搜索页按设置的来源顺序并行查询，不显示已关闭的来源。
- 清除缓存后计数立即更新，当前曲目已发布的歌词不会被重复获取。
- 新增插件自检诊断（默认关闭），用于排查问题；共用的启动流程改为诊断出错时不影响歌词 Hook。
- 上一个公开版本是 1.1.2；1.1.3 只是内部版本，以上匹配修复首次随 1.1.4 发布。

Universal Player Provider 1.1.4

- First release distributed through the ColorOS Live Lyrics Bridge store.
- Adds a status endpoint so the Bridge can show whether this module is enabled in LSPosed without root.
- Lyric sources follow the configured priority strictly: a lower-ranked source no longer jumps ahead because it has word timing or translations, and a credits-only result no longer ends the search early.
- More accurate matching: compares core titles without edition suffixes and every credited artist, no longer takes an instrumental upload for a sung track, tolerates spaced QRC timestamps, recognises lyricist/composer credit rows, and compares the top candidates within a score floor.
- An automatic miss is no longer cached permanently as "no lyrics": it is retried once the player supplies the artist or duration, and after the source order changes.
- The QQ Music search endpoints no longer fail together, so one failing endpoint does not drop the whole source; the search screen queries sources in the configured order in parallel and hides disabled ones.
- Clearing the cache updates the count at once and does not re-fetch the current track's published lyric.
- Adds a self-check diagnostics page (off by default); the shared startup now keeps lyric hooks running if diagnostics fail.
- The previous public version was 1.1.2; 1.1.3 was internal only, so these matching fixes ship for the first time in 1.1.4.
