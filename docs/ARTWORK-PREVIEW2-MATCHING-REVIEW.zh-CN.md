# C17 Artwork Preview2 匹配复查

日期：2026-10-07。范围：Provider 1.0.4（8）及配套 Bridge 预览；不改播放器歌词传输。

用户已确认 fix9 实机测试通过，并授权按惯例发布 Preview2。以下结论来自当前源码、回归测试和本地构建；两项收尾修复及最终签名包未另做设备 RC。

## 本轮发现与修复

1. **译名消歧遗漏短版本标签。** `Song (中文版)`、`Song (粵語版)`、`Song (重錄)`、`Song (現場)` 可能被当作跨文字译名删除。AM 与网易云均补齐这些版本保护。新增用例在修复前复现两项测试失败，修复后通过；所有严格度都拒绝原版与上述版本互配，但相同版本仍可匹配。查询决策分别升为 AM v8、网易云 v3，避免旧决策残留，保留已有完整视频和绑定。
2. **网易云单曲失败污染整张专辑。** 动态封面接口按 songId 作答，旧实现却把失败写到专辑视频索引。失败现按 songId、专辑及消费者上限隔离；旧专辑级失败不迁移，成功视频继续按专辑复用。并发下载共用专辑锁、按歌曲隔离失败；正在进行的上游限流仍共享退避。测试覆盖单曲失败、同专辑其它歌曲、共享成功视频和不同歌曲并发失败隔离。

## 复查覆盖

| 链路 | 静态检查与相关回归 |
| --- | --- |
| 来源路由 | 显式链接/绑定优先；缓存先行；冷查并发准备，AM 成功不等网易云，AM 失败后才下载网易云；只有最终结果更新状态 |
| AM 候选 | 专辑名优先、最多一次歌曲补查；真实曲目表校验；Explicit 线索、版本边界、6 页上限、未知候选不猜测 |
| 网易云候选 | 曲目名搜索、歌手/录音标记校验；专辑/时长排序，同分保留歧义；不凭动态封面存在与否选身份 |
| 查询与视频缓存 | 查询档位、市场、会话/网络代次和资源限制；重新验证专辑快照；成功文件 pin/独立租约；歌曲失败隔离 |
| 网络恢复 | 1/3 秒最多两轮、原请求总期限；只绕过临时传输失败；取消、限流、无封面、登录/续期失败不重放 |
| 手动搜索 | AM/网易云输入、结果和请求独立；最近记录分别填专辑/曲名；已验证的 JP Eagles 查询不再被另一来源改写 |
| 缩略图与来源 | 官方 HTTPS 图片 host、无凭据请求、来源隔离缓存；来源标签只用于显示；缺图不丢歌曲 |
| 会话与异步交付 | 私有加密、关闭/退出递增代次；resolve/openAsset 前复核；Bridge 55 秒预算保留同录音重挂载，换曲结果不能挂到新曲 |
| 媒体契约 | 两仓库 v1.1 镜像；最大 1280、AM 原生 1080；旧 1080 消费者仍拒绝超限资源，保持 FD 复验及静态降级 |
